2021/09/16
mva_generate.exe
1、新增提示音和code一键打包成MVA文件的小工具
2、使用命令行 mva_generate.exe main_merge.mva BT_Audio_APP.bin all.bin
3、main_merge.mva为输出的MVA文件，BT_Audio_APP.bin为code，all.bin为提示音
4、如果需要修改文件路径，可以..\..\MVsB1_Base_SDK\tools\remind_script\all.bin，其中每一个"..\"代表一层上级目录，也可以使用绝对路径
5、音频SDK的script_post.bat是给Andes调用的自动脚本文件，如有调整请修改脚本

b1_download_v0.6.exe

注：code在启动时使用快速4K CRC校验

------------------------------
b1_download_const_data_v0.5.exe
在AndeSight->Flash Burner中，使用该Flash Driver可以烧录任意的Const Data的bin文件（非0地址）；
